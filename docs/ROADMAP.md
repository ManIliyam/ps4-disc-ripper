# Roadmap

1. Expand finalized personal-DVD/model tests; validate real cancellation,
   disconnects, full-HDD handling and damaged-disc errors.
2. Add folder copying, selection, manifests, total-space budgeting and per-file status.
3. Investigate a supported automatic storage query, retaining honest Unknown states.
4. Add optional Windows transfer helper and PS4-initiated Windows transfers.
5. Validate USB destinations, filesystems and large-file limits.
6. Test accessible personal Blu-ray and DVD_RTAV recordings separately.
7. Investigate previews only with verified decoder/player APIs and formats.

CD-DA, raw optical access, unfinalized recovery and commercial DRM decryption are
not promised. Timing depends on verified interfaces and hardware tests.
